# Operator Quickstart

## Match-day flow

1. **Prepare**
   - Create/open the match in Match Setup.
   - Confirm teams, rosters, starting six for Set 1, court, and outputs.
   - Check that OBS/browser outputs are connected.

2. **Pre-match graphics**
   - Open **Live Control > Graphics**.
   - Use Match Intro, Team Intro, and Lineups as needed.
   - In **Direct** mode, selecting a graphic sends it to air. In **Preview then Take**, load preview then press **TAKE**.

3. **Start Set 1**
   - On **Live Control > Score**, press **Start Set 1**.
   - Confirm the pre-flight checklist and first server.
   - The match goes live and the set starts. Scoring is disabled until a set starts.

4. **Score points**
   - Use team +1 and action buttons. Select a player first to attribute an action.
   - Use **Undo** to reverse the last scoring/action event.

5. **End the set**
   - When a team reaches the winning score with the required lead, **End Set N** becomes available.
   - If end confirmation is enabled, scoring locks at winning condition until you confirm **End Set** (undo still works).
   - Use **End set early...** only for referee decisions; a reason is required.

6. **Set summary**
   - After ending a set, use the Set Summary panel:
     - **Show set stats full screen** (SET_ANALYSIS)
     - **Show set result** (SET_RESULT)
     - **Start break timer and slate**
     - **Start Set 2**

7. **Repeat / finish**
   - Repeat for each set.
   - After the deciding set, show final result and end the match.

## Keyboard map

- `Q` / `W`: +1 Team A / B
- `Z`: Undo last
- `E`: End set (when legal) / end set early dialog
- `F1`/`F2` or `!`/`@`: Timeout A/B
- `1-7`: Load graphic
- `Enter`: TAKE preview to program
- `Esc`: CLEAR program
- `O`: Outputs
- `?`: How a match runs / shortcuts
